# KoDe-L Dev 🌐

Site web vitrine d’une agence digitale spécialisée dans la création de sites web modernes et le design infographique.

## 🚀 Présentation

KoDe-L Dev est un site vitrine professionnel conçu pour présenter :

* Les services digitaux
* L’agence
* Les informations de contact
* Une interface moderne avec animations et thème sombre

Ce site est responsive, élégant et optimisé pour une présence en ligne professionnelle.

## 🛠️ Technologies utilisées

* HTML5
* CSS3 (animations + responsive design)
* JavaScript (thème sombre + animations)
* Font Awesome (icônes)

## 🎨 Fonctionnalités principales

* Design moderne et professionnel
* Mode sombre (Dark Mode avec sauvegarde)
* Animations au scroll (services)
* Animation section "À propos"
* Bouton WhatsApp flottant
* Interface responsive (mobile, tablette, PC)
* Navigation fluide (scroll smooth)

## 🌙 Mode sombre

Le site intègre un bouton "Thème" qui permet :

* De basculer en mode sombre
* De sauvegarder le thème avec LocalStorage
* De garder le thème même après actualisation
